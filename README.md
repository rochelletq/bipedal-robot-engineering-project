# bipedal-robot-engineering-project

# overview 
Second-year engineering group project focused on using Adruino C++ to design, build and test a bipedal robot capable of walking and squatting
# my contribution
- project manager and software development
- assisted with software testing and debugging
- organised team meetings and maintained the kanban board
# software
- Arduino C++
- M5Stack
- I2C communication
- servo control
- joystick input

  # code explaintation
- the robot software processes the joystick input to then control a series of servos to produce walking a squat movements
- the servo postitions change incrementally rather than jumping between positions to create smoother transtitions between each movement
- the robot was testing through separate servo, walking and squat tests.
- the final robot sucessfully walked and completed a squat with a 435g load
